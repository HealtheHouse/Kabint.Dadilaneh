نرم‌افزار مدیریت مالی برادران دادیلانه – نسخه حرفه‌ای آماده GitHub Pages

ویژگی‌های این نسخه:
- ظاهر حرفه‌ای و نزدیک به نرم‌افزارهای حسابداری
- منوی کناری، داشبورد، کارت‌های مالی و رابط کاربری واکنش‌گرا
- اطلاعات در مرورگر ذخیره نمی‌شود؛ دیتابیس مرکزی Supabase است.
- استفاده از نرم‌افزار از چند کامپیوتر با یک حساب و یک دیتابیس مشترک
- فیلتر ستونی و مرتب‌سازی صعودی/نزولی مانند Excel در جداول اصلی
- بخش مستقل «چک» با دو دفتر «چک‌های صادرشده» و «چک‌های دریافتی»
- حذف محاسبه متراژ کابینت
- حذف گروه‌ها و بابت‌ها

راه‌اندازی یک‌باره Supabase:
1) یک پروژه در Supabase بسازید.
2) فایل supabase_schema.sql را در SQL Editor اجرا کنید.
3) در Authentication > Users یک کاربر بسازید.
4) فایل seed.sql را در صورت نیاز فقط یک‌بار برای ورود اطلاعات اولیه اکسل اجرا کنید.
5) از Project Settings > API مقدار Project URL و anon public key را بردارید.
6) همین دو مقدار را در config.js وارد کنید. service_role key را هرگز وارد نکنید.

انتشار در GitHub Pages:
1) یک Repository جدید در GitHub بسازید.
2) همه فایل‌های همین پوشه را در ریشه Repository آپلود کنید؛ index.html باید مستقیماً در ریشه باشد.
3) از Settings > Pages، گزینه Deploy from a branch را انتخاب کنید.
4) Branch را روی main و Folder را روی /(root) بگذارید و Save کنید.
5) پس از انتشار، آدرس GitHub Pages را از همان صفحه بردارید.
6) همان آدرس را در هر کامپیوتر باز کنید؛ داده‌ها از Supabase خوانده می‌شوند.

نکته امنیتی:
- anon public key برای نرم‌افزار سمت کاربر قابل استفاده است، اما باید Row Level Security در Supabase فعال باشد.
- service_role key را داخل GitHub، index.html یا config.js قرار ندهید.
